提示词 (源自网络): 
设计并制作一个极具创意、精巧复杂且细节丰富的体素（voxel）艺术场景：
超现实云鲸星轮，一头巨大的飞鲸浮游在浩瀚云海之上，
鲸背之上矗立一套巨型星象轮盘机械作为核心主体，巨大的镂空星轮架设在鲸背中央，轮盘流转着星光纹理；
星轮两侧耸立两座东方风格的高塔，木构楼阁层层叠叠，发光窗灯错落排布。
鲸背坡面散落小型民居、风车、拱桥、花园与栈道，热气球悬停在鲸背上空。
场景点缀飞鸟、蝴蝶等小型动物。
自然元素包含翻滚云海、高空薄雾、流星光轨、浮空碎岩与发光粒子。
色彩鲜明，通透光影，白天是澄澈蓝天晨光，夜晚切换为星空月夜，带有柔和逆光、体积云与梦幻光晕。
可自由使用 Three.js 等库（通过 CDN 引入）。
交付产物是纯前端静态站点，具有清晰锐利的体素边缘，支持多视角观察、场景内自由移动、相机旋转平移缩放。
发挥全部潜力，大胆设计，科学规划，分工协作，自检优化。
